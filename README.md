Throughout my Software Engineering career I had the chance to work on some projects that I am very proud of:

### Sui Stack Messaging SDK
I owned the full technical design and implementation of an on-chain Messaging primitive for the Sui Blockchain
and an accompanying ts-sdk.

Links:
- [alpha repo](https://github.com/MystenLabs/sui-stack-messaging-sdk)
- [alpha announcement](https://www.sui.io/blog/sui-stack-messaging-sdk)
- [beta repo](https://github.com/MystenLabs/sui-stack-messaging)
- [beta announcement](https://www.sui.io/blog/messaging-sdk-beta-live-mainnet)

### Sui Groups
An on-chain extensible ACL library for the Sui Blockchain.
Used by the **Sui Stack Messaging SDK(beta)** and the **Walrus Console** projects.
I am especially proud of the [Actor Object pattern](https://github.com/MystenLabs/sui-groups/blob/main/docs/Extending.md#step-2-the-actor-object-pattern) I came up with, which enables third-party 
smart-contracts to safely extend its core functionality.

### Walrus Console
A Dropbox-like application built on top of the [Walrus](https://docs.wal.app/) Decentralized Storage Protocol
I got the chance to take on the Tech Lead Role for the first time, leading 7 Software Engineers.
My responsibilities spanned across Technical/Architectural designs & decision making, project management, extensive code-reviews
and mentoring.

Links:
- https://console.walrus.xyz
- [announcement](https://walrus.xyz/blog/introducing-walrus-console/)
- [docs](https://docs.wal.app/docs/console/overview)

### Walrus Sites
Decentralized websites built on Sui and Walrus.
I was one of the core maintainers of the project.
My biggest contribution was leading the technical design for integrating with the [Walrus Quilts](https://docs.wal.app/docs/system-overview/quilt) primitive,
which massively improved costs & performance.

Links: 
- https://wal.app/
- [repo](https://github.com/MystenLabs/walrus-sites)
- [docs](https://docs.wal.app/docs/sites)
